## 六、必背清单（考试范围就这些）

### 必背数字

| 数字 | 含义 |
|------|------|
| 97.5% | 混合检索 Top-5 命中率 |
| 87.5% | 混合+重排 Top-1 命中率 |
| 65% → 87.5% | 重排带来的 Top-1 提升 |
| 100% | RAG 回答引用率 |
| 17ms | 热缓存命中延迟（未命中 4-6 秒） |
| 64 / 123 | 知识点数 / 分块数 |
| 35 | 单元+集成测试数 |
| 31.8ms | 本地检索平均延迟 |
| 3.7s | 一次 AI 问答总耗时（95% 是模型生成） |

### 必背一句话（可随时兜底）

- **项目**："面向大学生的智能学习平台：学-测-评-荐 + RAG AI 助教，前后端分离、双后端架构。"
- **RAG**："回答前先从资料库检索相关片段，连同问题给模型，让它看着资料回答——有依据、可溯源、防幻觉。"
- **重排**："粗排结果太糙，用 LLM 给候选打分重排，把 Top-1 命中从 65% 提到 87.5%。"
- **为什么没用 MQ**："当前变更频率低，HTTP 直调够用；生产会换 MQ，并处理重复消费幂等。"
- **收尾话术**："我的方法论是先想清楚为什么再动手，每个选择有备选，并用数据验证；我知道生产会换什么。"
